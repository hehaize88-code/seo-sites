# rizzitgotab.com

Production RizzitGO catalogue. All product records and gallery assets are read from cnfanshm.com. No product database. Image fingerprints derive from source images.

Build: `npm run build`. Cloudflare Worker: `rizzitgotab-com`. Root directory: `rizzitgotab.com`. Deploy: `npx wrangler deploy`.

Source image index: 6,041 products / 25,676 images; live Weidian option images are not all indexed. Copy selection includes original item link and SKU text.
