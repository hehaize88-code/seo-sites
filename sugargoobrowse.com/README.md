# Sugargoo Browse

Production: https://sugargoobrowse.com

Cloudflare Worker; build `npm run build`, deploy `npx wrangler deploy` from this directory. All catalog data and photos are fetched from cnfanshm.com. Search fingerprints are derived from source photos; no product database. Eight language routes, live exchange rates, source buying links, and XML sitemaps. www and HTTP redirect to HTTPS apex.
