How to use this page

W2C means “where to cop.” Start with the product name or spreadsheet row, confirm the category and image, then open the live route and verify price, size and availability.

Marketplace IDs and catalogue numbers are different

A Weidian item ID does not automatically equal the number in a catalogue product URL. This tool uses the site's existing mapping for known entries. For example, source ID 7777852466 maps to the footwear record ending in 6078.html. It does not invent a product URL ending in the longer source ID.

Paste a Weidian link containing itemID, a Taobao link containing id, a 1688 offer link, a known catalogue link or a product keyword. Recognised source IDs are checked against the existing mapping; unmatched values go to search. A search result is still a lead, not proof of an identical product.

Check the result before ordering

  1. Compare the image, title, source item ID and seller context.
  2. Recheck colour, size, quantity and version options.
  3. Review the current price and any domestic delivery charge.
  4. Save the exact selection and measurements needed for QC.

If a short link hides the source ID, open the original listing yourself and copy its full product link. Never paste account, payment or private order links. If the tool cannot identify an item, search its name and compare the results instead of assuming the first result matches.
