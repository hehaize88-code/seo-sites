LoloBuy W2C：商品链接与来源 ID 查找

粘贴商品链接、来源商品 ID 或关键词。工具会打开已知的目录匹配，或搜索候选商品。它不能确认卖家库存，也不会把未知 ID 拼成看似确定的商品页。

使用方法

W2C 是“Where To Cop”的缩写，意思是“哪里可以买到”。从商品名或清单记录开始，确认分类和图片，再打开实际商品页核对价格、尺码和库存。

浏览 W2C 商品链接 →

原平台商品 ID 与目录编号不同

微店的商品 ID 不自动等于目录网址中的编号。本工具只使用已经建立的对应关系。例如，来源 ID 7777852466 对应以 6078.html 结尾的鞋类目录记录，不会用较长的原商品 ID 凭空生成一个目录地址。

可以输入含 itemID 的微店链接、含 id 的淘宝链接、1688 商品链接、已知目录链接或商品关键词。已识别的 ID 会核对现有映射，未匹配的内容会进入搜索。搜索结果只是线索，不足以证明是同一件商品。

下单前核对搜索结果

  1. 比较图片、标题、来源商品 ID 和卖家信息。
  2. 再次核对颜色、尺码、数量和版本选项。
  3. 检查当前价格及中国境内运费。
  4. 保存准确的选择，以及质检需要核对的尺寸。

短链接隐藏商品 ID 时，请自行打开原商品页并复制完整地址。不要粘贴账户、付款或私人订单链接。工具识别不了商品时，可以搜索名称并比较结果，不要默认第一项就是正确商品。
