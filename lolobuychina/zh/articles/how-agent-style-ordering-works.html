代购流程将商品采购与国际包裹运输分成不同阶段。了解这些环节，有助于把正确的商品链接、规格选择与相关证据保存在一起，避免把一张商品卡片误当成完整的购买方案。

1. 从准确的商品来源开始

打开商品卡片，确认目标页面确实对应想看的商品。比较图片、标题、卖家信息、可选规格和商品编号。通用标题很常见，因此应同时核对多个细节，不能只凭标题中的一个词判断。

提交订单前，记录原始链接、商品 ID、所选颜色、尺码、版本和数量。如果同一页面有多个相似款式，把具体选择保存到备注中。截图可以保留卖家修改页面前的可见信息，但当前价格与可购买情况仍应以实时结算页面为准。

2. 入库前核对订单

商品标价不是最终到手总成本。中国境内配送、可选服务、支付换汇与国际运费可能在不同阶段收取。在美元估价旁保留原币种金额，并在确认付款前核对应付金额。

下单后持续查看当前订单状态。不要假设所有卖家的发货速度相同，或都接受同样的售后申请。商品延迟、变更或缺货时，应使用该笔订单实际提供的处理选项。

3. 将入库实物与所选规格对应

商品入库后，将仓库记录与保存的选择核对，检查品类、颜色、数量、版本及可见尺码标签。仓库照片是验收依据，不只是展示图片。重要细节缺失时，在平台提供相应服务的前提下，申请针对性的补拍或测量。

4. 作出明确的 QC 决定

把每件商品标记为已接受、需要澄清或需要处理。按品类检查整体形状、可见结构、印花或刺绣位置、走线、五金、标签、包装及关键尺寸。只有验收通过的商品才应进入发货计划。

5. 使用当前数据规划包裹

所选商品准备好后，核对实际重量、尺寸、商品类别和可用线路。合包可能减少重复的首重或基础费用，但更大的外箱也可能提高体积重。应按能否共同运输来组合商品，而不只按到货日期组合，并在提交包裹前核对当前结算条件。

最终下单检查清单

  • 目标页面和所选规格与原本想买的商品一致。
  • 已记录原始链接、商品 ID 和规格选择。
  • 仓库收到的商品与订单备注一致。
  • 提交包裹前已解决质检中的疑问。
  • 仅将验收通过的商品放入同一发货计划。
  • 已核对当前线路、重量、尺寸和最终费用。
独立指南提示：商品可购买情况、服务、线路和费用都可能变化，付款前应核对当前商品页、订单、仓库记录和包裹页面。

建立商品、实物与包裹三份记录

分别保存商品来源、实际收货和发货包裹三份记录。来源记录保存原链接、来源 ID 和所选规格；收货记录保存实际到货情况及质检决定；包裹记录保存准备发出的已验收商品、包装选择和当前线路报价。修改其中一份记录时，不应悄悄覆盖另一份记录中的信息。

例如卖家替换了颜色，应先更新订单处理决定，再决定是否接受仓库照片中的商品。如果之后申请更换尺码，替换来的商品也要单独检查。之前的验收只针对原来的实物，不代表同名的所有商品都已通过验收。

处理不明确的商品链接

使用商品链接查找器，将已知来源 ID 对应到现有商品目录。来源未知时，搜索名称或 ID 后自行比较结果。没有已确认的对应关系时，不要把外部平台的商品 ID 直接拼成目录页面地址。

商品链接查找器

鞋类可以参考鞋款测量指南；服装应先比较实际尺寸，再参考尺码字母。保留尚未解决的问题，避免在结算时无意中批准了有疑问的商品。

记录每件商品的下一步

为每件商品写明下一步：等待卖家信息、等待到货、核对证据、申请可提供的纠正措施，或已准备提交包裹。记录日期和原因，比所有商品统一显示“处理中”更方便核对多卖家订单。所有截止时间均应以当前账户条款为准。
