LoloBuy Returns & Refunds: Cancel an Order and Track Your Refund

LoloBuyChina Editorial · Updated 31 October 2026

Start a LoloBuy cancellation or return request from the exact order and its current stage. An unpaid order, a seller purchase, an item stored in the warehouse and an international parcel require different checks. Keep the request, returned item and money movement as separate records so you can see what has actually been completed.

Record the current order stage before taking action

Open the relevant order and save its reference, selected variant, quantity, payment record and current status. Check whether purchasing has started, whether the seller has dispatched, whether warehouse inspection is available and whether the item has been included in a parcel. Use the wording visible in your account rather than assuming that an older tutorial has the same buttons.

Note what you want: cancellation before purchase, return of a received item, replacement with a different option, or clarification of a refund already approved. These are different requests. If several items share one payment, identify the item and quantity concerned so that a request for one product is not interpreted as a request about the whole order.

Distinguish cancellation from a warehouse return

For an unpaid order, first confirm that no payment or balance deduction was completed. Removing an unpaid request is not evidence that money has been refunded. For a paid order that has not yet been purchased, check the cancellation action available in the account and obtain confirmation that the purchasing process has stopped. Sending a message does not itself cancel an order.

If the seller has already dispatched, cancellation may involve a return rather than simply stopping a purchase. Ask which process applies to that item and whether any freight or handling remains payable. Do not submit a replacement order merely because the first request is pending; you could end up with two accepted purchases.

Inspect warehouse evidence promptly

When warehouse photos become available, compare the received item with your saved source link and selected option. Record a wrong colour, size label, quantity, missing accessory or visible defect precisely. Ask for a focused photograph or measurement when the available evidence cannot resolve the issue and that service is offered for the order.

Keep inspection decisions separate from parcel submission. If you are requesting a return, check whether the item can be held out of a parcel while the request is reviewed. Do not approve international dispatch of an unresolved item on the assumption that it can always be recalled later. Save the actual response confirming the item's status.

Verify the applicable return window and conditions

Read the current terms for the purchased item and the order's displayed deadline. Record the event from which any window runs, the relevant time zone and the last permitted action. A storage allowance is not a return allowance. Free warehouse storage does not mean that a seller will accept a return throughout the same period.

Seller conditions can differ by product, customisation and purchasing channel. LoloBuy's public manual-entry form specifically warns that some third-party purchases may not offer the same return or exchange service as ordinary marketplace orders. Do not assume that every listing is eligible or that a missing deadline means unlimited time.

This guide does not state a universal return deadline, refund processing time or guaranteed fee. If the account terms are unclear, ask support to confirm eligibility and the relevant deadline for the exact order. Retain that answer alongside the order record instead of relying on a promotional page or another buyer's experience.

Prepare an evidence-based request

Include the order reference, item identifier, selected variant, quantity, the reason for the request and the outcome you are seeking. Attach the source screenshot and the relevant warehouse image. Explain the difference concretely: a different labelled size, an absent component or a visible defect. Keep the original image so that a crop does not remove useful context.

For a sizing problem, distinguish a wrong delivered size from an item that matches the ordered label but does not fit your expectations. Include the seller's measurements and your requested measurement method when available. This distinction helps the service assess the request without implying that one explanation guarantees approval.

Use the official order or support channel to send private evidence. Public review pages are not a substitute for submitting the request within the applicable process. Keep a dated copy of the request and the reply, and follow the instructions actually given for that item.

Compare the refund amount with the full cost

Ask for the expected refund breakdown before accepting an optional paid return service. Keep the item amount, original domestic freight, return freight, service charges and any disclosed payment adjustment in separate fields. Whether each amount is recoverable depends on the transaction and the applicable conditions; a product refund should not automatically be treated as a refund of every cost.

Consider a hypothetical item costing 100 CNY with 10 CNY paid separately for domestic delivery. If an approved refund is 100 CNY and a further 12 CNY return cost remains payable, the result is not a recovery of the full 110 CNY originally spent. These are illustrative figures, not LoloBuy charges. Replace them with the amounts confirmed for your order.

For a partial return, record the quantity returned and the allocation shown in the actual refund record. Do not divide a combined payment equally between differently priced items unless that is how the platform describes the refund. Keep the original currency so that later conversion changes do not obscure the underlying amount.

Track the item movement and the refund separately

A return being approved, a parcel being sent back, a seller receiving it and a refund being recorded are separate events. Save the evidence available for each stage, including a return reference when provided. A tracking label marked delivered describes a package movement; it does not alone establish that a financial refund has been processed.

For the money record, note the approved amount, currency, destination and transaction reference. A credit appearing in the platform balance and money arriving at the original payment method are different outcomes. Read the actual refund destination before looking for a bank credit, and check any separate withdrawal process only if it is relevant and available to your account.

Follow up on a refund that remains unclear

Use the processing expectations supplied for your case. When following up, quote the request reference, approval date, confirmed amount and the last completed stage. Explain what is missing: return receipt confirmation, a refund transaction, a balance update or receipt by the payment provider. This is more useful than repeatedly asking whether the whole order is finished.

Preserve any new response and update the same timeline. Avoid creating multiple contradictory requests for the same item. If the recorded amount or destination differs from the approval, provide both records and ask for reconciliation. Do not label a refund lost merely because you checked the wrong account or payment destination.

Close the record before ordering a replacement

Confirm the outcome of the original item, any remaining charges and the refund destination. A replacement may need a new source check, current price, stock confirmation and fresh inspection. Review its measurements independently, even when the title and seller are unchanged. Keep the replacement order distinct from the returned item in your notes.

Use the tracking guide to separate domestic and international journeys, and the total-cost worksheet to reconcile the money. The QC checklist helps you record a clear decision before the next parcel is submitted.
