이 페이지 사용 방법

W2C는 “where to cop”, 즉 구매처를 찾는다는 뜻입니다. 상품명이나 목록의 행에서 시작해 카테고리와 사진을 확인한 다음 실제 상품 페이지에서 가격, 사이즈, 구매 가능 여부를 검토하세요.

마켓 상품 ID와 카탈로그 번호는 다릅니다

웨이디엔 상품 ID는 카탈로그 URL의 번호와 자동으로 일치하지 않습니다. 이 도구는 이미 확인된 상품의 대응 관계를 사용합니다. 예를 들어 원본 ID 7777852466은 주소가 6078.html로 끝나는 신발 상품 기록에 연결됩니다. 긴 원본 ID를 넣어 존재 여부가 확인되지 않은 상품 URL을 만들지 않습니다.

itemID가 포함된 웨이디엔 링크, id가 포함된 타오바오 링크, 1688 상품 링크, 알려진 카탈로그 링크 또는 상품 키워드를 입력하세요. 확인된 원본 ID는 기존 대응 관계와 대조하고 일치하지 않는 값은 검색합니다. 검색 결과는 단서이며 같은 상품이라는 증거는 아닙니다.

주문 전에 검색 결과 확인

  1. 사진, 상품명, 원본 상품 ID, 판매자 정보를 비교하세요.
  2. 색상, 사이즈, 수량, 버전 옵션을 다시 확인하세요.
  3. 현재 가격과 중국 내 배송비를 확인하세요.
  4. 정확한 선택 옵션과 QC에 필요한 실측 항목을 저장하세요.

단축 링크에 원본 ID가 보이지 않으면 원래 판매 페이지를 직접 열어 전체 상품 링크를 복사하세요. 계정, 결제 또는 비공개 주문 링크는 입력하지 마세요. 도구가 상품을 식별하지 못하면 이름으로 검색하고 결과를 비교해야 하며 첫 결과가 일치한다고 가정하면 안 됩니다.
