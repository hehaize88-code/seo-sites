Compare the seller’s chart with measurements taken using the same units and endpoints. Flat garment width, body circumference and recommended fit ranges are different measurements.

A HooBuy size chart is useful only when its numbers describe the same measurement you can reproduce. Choosing by a familiar letter, height range or automatic conversion can create false confidence because two sellers may use the same label for different finished dimensions.

The spreadsheet method below preserves the original chart, defines each endpoint and compares it with a garment or foot measurement taken the same way. It also keeps uncertainty visible. The aim is not to predict a perfect fit; it is to make a better documented choice and know which later warehouse evidence could reveal a mismatch.

Verify the exact listing and selected variant first

Open the final destination page and save its marketplace, item identifier, seller identity, final URL and verification date. Select the intended color, version and other options before copying the size chart. Some pages reuse images or display information that may not apply equally to every option.

If the destination, seller or item cannot be reproduced, pause the sizing decision and use the product-link verification workflow. Accurate measurements attached to the wrong listing remain wrong evidence.

Preserve the original chart before normalizing it

Record every source size label, value, unit, measurement name, tolerance statement and explanatory note exactly as displayed. Keep the observation date. If you make a private reference image where permitted, also transcribe the important values into structured cells so they can be filtered and compared.

Add normalized columns only beside the source data. A conversion formula should never overwrite the original number. Round consistently and avoid manufacturing precision; a whole-centimeter chart does not become more accurate when converted to two decimal places.

Classify every value by measurement type

Use explicit types: body measurement, finished-garment measurement, flat measurement, circumference, foot measurement, insole length, interior length or outsole length. Values with different types should not be compared directly even when their units match.

If the chart simply says “chest” or “length” without a diagram or method, mark the endpoint as not stated. Do not resolve ambiguity by choosing the interpretation that best supports the desired size. Write one clear blocking question instead.

Core rule: same label plus same unit does not mean same measurement. Compare only values with matching object, endpoints, state and method.

Choose a reference item that already fits

For clothing, select a garment of similar type and intended fit. Lay it on a flat surface without stretching it. Measure the endpoints used by the seller chart, repeat important values and record the date, tool and reference item.

For footwear, measure the intended foot using a consistent method and time, then compare only with a chart that clearly states a compatible basis. A labeled shoe size or a generic country conversion should remain a separate clue rather than replacing the listing-specific evidence.

Account for construction and intended fit

A chest measurement alone cannot describe shoulder width, armhole shape, fabric behavior or preferred ease. Create fields for the intended fit—close, regular or oversized—and for construction details that materially affect the decision. Keep these as decision inputs, not universal rules.

Compare several dimensions when available. A size may appear suitable at the chest but fail on body length or sleeve path. The spreadsheet should flag the conflicting dimension rather than averaging everything into one “good” result.

Handle stretch and tolerance cautiously

If a listing states a measurement tolerance, preserve the exact wording and unit. Do not apply a tolerance from one seller to another. If stretch is claimed, record where the claim appears, but do not invent a stretch percentage or assume that elasticity produces a comfortable fit.

Create low and high comparison bounds only when the source supports them. When no tolerance is provided, label the value as a point observation with unknown production variation. Visible uncertainty is more honest and useful than a made-up safety margin.

Keep size recommendations separate from measurements

Seller recommendations based on height, weight or a message belong in attributed fields with the date and exact selected variant. They can be considered, but they should not overwrite the chart or the reference-item comparison.

If a recommendation conflicts with reproducible garment measurements, expose the conflict and pause. The next useful step is clarification, not silently selecting whichever answer feels safer. Record who supplied the recommendation and what information they used.

Build a simple comparison calculation

For each matching dimension, calculate candidate measurement minus reference measurement. Keep the result in the same unit and label its direction. A positive value means the candidate is larger on that measured path; it does not automatically mean the fit is better.

Add a decision band based on the intended fit and the user’s own acceptable range. This is a personal preference field, not a platform standard. If only one important dimension matches while another is absent, the status should remain incomplete.

Plan measurement QC without overclaiming

Before ordering, identify which selected-size label and finished-product measurements need confirmation after warehouse arrival. State the exact endpoints and whether the garment should be laid flat. Use statuses such as pending, readable, measured, method unclear, mismatch or not shown.

A tag photo can confirm a visible label but not the true garment dimensions or fit. A tape photo can show a measured path only if both endpoints and the reading are clear. Neither proves comfort, drape after wear or production consistency beyond the specific item.

Worked example: two hoodies labeled large

Candidate A lists a flat chest width and back length with a diagram. Candidate B uses the same “L” label but provides only a body-weight suggestion. The reference hoodie has measurements taken with endpoints matching Candidate A.

A can be compared dimension by dimension and moved forward if the differences meet the intended fit. B remains unresolved because its recommendation uses a different evidence type. Calling both products the same size would hide the most important difference in the record.

Use stop conditions instead of optimistic guesses

  • The chart cannot be tied to the exact listing or selected variant.
  • Measurement type or endpoints are not stated for a critical dimension.
  • Units are missing or a translation is ambiguous.
  • The candidate and reference measurements use incompatible methods.
  • An important dimension conflicts with the intended fit.
  • A recommendation conflicts with the reproducible chart.
  • The selected size is unavailable or changes another product option.
  • The after-sale assumption has not been checked in the live account.

Minimum size-chart spreadsheet fields

  1. Stable candidate ID and verified listing identity.
  2. Exact selected option labels and observation date.
  3. Original chart values, units and notes.
  4. Measurement type and defined endpoints.
  5. Normalized values in separate calculated columns.
  6. Reference item and matching measurement method.
  7. Intended fit and acceptable comparison range.
  8. Seller recommendation stored as attributed evidence.
  9. Conflicts, unknowns and blocking questions.
  10. Planned warehouse checks and final decision reason.

Freeze the decision, then append later evidence

Before ordering, save the row version that informed the choice. After warehouse arrival, append the received label and measurement evidence without replacing the source chart. A mismatch should remain visible so the buyer can inspect current options using the correct record.

The wider HooBuy spreadsheet guide explains how to maintain status and verification dates. Used together, these fields turn a size chart from a persuasive image into an auditable comparison: exact source, matched method, visible uncertainty and a clear next action.
