Build a Hoobuy spreadsheet that stays useful

Use dated source records, selected variants and decision-changing evidence instead of collecting bare product links.

From a W2C link to a research record

A useful spreadsheet explains where a listing came from, which seller and option were checked, and when the record was last verified. A bare URL can become misleading when a seller changes the title, price or available variants.

For every candidate, record the source marketplace, seller, exact listing, selected colour and size, link status, reference images and the checks still needed. Separate confirmed facts from estimates so an old note is not mistaken for current platform data.

After warehouse arrival, update the same row with QC status, visible condition, measurements, missing evidence and any follow-up request. The record should make the next action clear: approve, hold, request evidence, return or remove.

Shipping amounts, photo services, exchange rates and promotions can change. Confirm those details in the current account, warehouse service panel and checkout instead of treating an old spreadsheet value as a permanent quote.

Recommended fields

  1. Product name, category, source marketplace and seller.
  2. Exact URL, selected variant and date last verified.
  3. Price basis, domestic freight note and any unconfirmed estimate.
  4. QC status, measurements, visible condition and follow-up evidence.
  5. Packed weight, dimensions, route notes and protection choice.
  6. Final decision with a short reason and review date.
