普通订单页告诉您当前标签；有用的跟踪表告诉您哪些证据支持该标签、预期下一行动方是谁，以及与上次检查相比有什么变化。当一个平台采购拆成多个境内包裹、快递先标记签收而仓库收货尚未出现，或一个入境包裹产生多个仓库商品 ID 时，这一区别尤其重要。

下面的工作表围绕交接而非承诺期限设计。Hoobuy 公开帮助资料将购物、配送、仓库、质检和存储分成不同服务领域；其转运指南也强调境内运单号及生成的转运订单 ID。这些公开步骤支持将标识分开保存。列设计和升级处理方法属于独立编辑建议。

一行应代表一件预期商品

商品可以独立移动时，不要用一行代表整批采购。有效单位是一件关联来源及所选规格的预期商品。一个卖家订单可能含三件商品，卖家用两箱发出，仓库之后分配三个商品 ID。如果行一开始就写‘整单’，这些关系会很难描述。

创建稳定记录 ID，例如 HB-2026-001。它是您的私密参考编号，不是平台标识。状态改变时也不要改变它。官方或平台编号应各放独立列。这样可防止转运订单 ID 覆盖境内运单号，或仓库商品 ID 覆盖原来源记录。

八组重要字段

1. 来源身份私密记录 ID、来源 URL、实时商品标题，以及卖家或平台参考编号。
2. 采购指示准确颜色、尺码、型号、数量，以及识别选择所需的买家备注。
3. 订单身份代购订单 ID；商品另行购买时则为转运订单 ID。
4. 境内移动快递公司、运单号、包裹数量和最新承运商事件。
5. 仓库收货收货日期、仓库商品 ID，以及预期数量是否匹配。
6. QC 决定可见身份、规格、数量、状况、尺寸，以及任何具体缺失证据。
7. 包裹交接合包组、包装选择、线路检查和提交后的包裹 ID。
8. 下一步行动一个责任方、一个请求结果，以及下次检查的 UTC 时间戳。

时间戳很重要，因为‘还在等’没有起点。统一使用一种格式，最好是 UTC；如需不止最新事件，可另建状态历史工作表。不要不断覆盖最后核实事件。简短历史——面单创建、承运商接收、签收、仓库匹配——就能准确显示交接停在哪里。

如何记录采购和卖家发货

采购时保存来源 URL 和准确所选选项。下单后商品页可能变化，因此应用明确文字写出规格，不要只依赖后来的截图。如果卖家要求不同金额或替换选项，应添加带日期备注，不要悄悄更改原指示。

记录卖家发货时，应区分运单号与承运商接收。卖家可能在快递拿到包裹前就提供号码。把号码放入追踪列，再单独记录最后已核实物流事件，这样能区分‘号码存在’‘承运商已接收’‘运输中’和‘已签收’。如果卖家拆单，复制必要来源字段，并为每件实体包裹建立自己的快递记录。

如何记录转运订单

转运订单始于您或其他寄件人已购买商品之后。Hoobuy 公开转运指南要求获取当前仓库地址、提供给寄件人、输入境内运单号并保存生成的转运订单 ID。所有这些层级都应保留。

每件预期商品一行，再将其关联到正确入库包裹。一个快递号码对应多件商品时，可以在各商品行重复该号码，或另建 Packages 工作表并用查找键关联。若有多个快递号码，不要用逗号分隔后放在一个单元格。分行会让缺失包裹检查和客服消息清楚得多。

公开指南说明，数量较多或体积较大的商品可能会分开拍照和存放，并生成多个商品记录。补充后续仓库编号时，不要删除转运编号或快递单号。表格应呈现以下对应关系：原始商品 → 实体国内包裹 → 转运记录 → 仓库商品。

把 QC 变成可以明确判断的事项

“QC 通过”过于笼统，不利于日后复查。请使用具体字段：商品身份是否一致、所选规格是否一致、数量是否一致、可见品相是否可接受、是否检查尺寸，以及还缺少什么证据。按品类记录的备注也要具体。鞋类可能需要核对型号、尺码标签、外底和左右鞋对称性；服装可能需要核对尺码标签、宽度、长度、印花位置和可见缝线；配饰可能需要核对尺寸、随附部件和五金件。

QC 照片只能提供可见证据，不能证明真伪、内部结构、耐用性或上身是否合适。如果缺少必要细节，请在下一步操作栏写下一个明确请求，例如“正面拍摄尺码标签”或“拍摄胸宽，确保卷尺刻度可见”。申请额外服务前，先在当前账户中确认是否提供以及价格；不要在表格中假定所有订单都享有统一的免费照片数量或收费标准。

使用负责人和下一步操作栏，避免重复跟进

每一行未解决的问题都应明确当前由谁处理：买家、采购代理、卖家、国内承运商、仓库入库人员、QC 人员或包裹团队。然后写下一项预期结果。“查一下订单”不够具体；“确认快递单号 X 是否已匹配到转运编号 Y”则能明确缺失的交接环节以及需要的证据。

最新证据可能的处理方有用的下一步操作
没有承运商揽收记录卖家或采购方确认实体包裹是否已交给指定承运商。
有签收扫描，但没有仓库记录快递与仓库入库交接环节核对快递单号、目的地、包裹数量和订单对应关系。
已有仓库编号，但可见细节不清楚买家或 QC 判断环节申请更多证据前，先明确缺少的一个拍摄角度或测量项目。
QC 已接受，但尚未创建包裹买家检查合箱、包装、当前线路适用条件和最新报价。

隐私与维护规则

  • 不要保存密码、银行卡号、钱包凭据、身份证明文件或完整家庭住址。
  • 限制共享权限。提供给客服的导出文件只应包含与该问题相关的行。
  • 保留原始来源和所选规格；修改时追加带日期的记录，不要覆盖历史。
  • 按固定节奏检查仍在处理中的记录，但不要自行设定适用于所有情况的期限。
  • 归档已完成记录，而不是删除。它们有助于说明复购情况和卖家的分包习惯。
  • 根据旧记录采取行动前，重新核对当前服务规则、仓库说明和线路信息。

表格只有在帮助明确下一步问题时才有价值

目标不是收集每一张截图，而是保留足够的证据，确定最后一个已完成的交接环节，以及下一个尚缺失的环节。来源和规格字段说明应该购买什么；承运商字段说明实体包裹是否发生移动；仓库和 QC 字段说明收到什么以及能看到什么；完成商品处理决定后，才开始填写包裹字段。

可以从可下载模板开始，再删除确实不需要的列。最有用的记录应简洁、一致，并且能够安全地按需共享部分内容。要深入了解各状态，请继续阅读 订单状态指南。自行在淘宝或微店购买的商品，请参阅 转运订单指南.
