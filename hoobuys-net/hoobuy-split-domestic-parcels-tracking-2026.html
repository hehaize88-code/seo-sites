Hoobuy Split Domestic Parcels: Match Tracking Numbers to Warehouse Items

Published and fact-checked: September 11, 2026 · 1,202 words

Independent-site disclosure: hoobuys.net is an independent workflow guide and is not HooBuy. Interface labels, seller messages, warehouse procedures and policies can change. Verify the current order record and current official terms before acting.

Hoobuy split package tracking becomes necessary when one seller order produces more than one domestic parcel. One number may start moving while another has only electronic information. One package may be delivered and stored while the remaining item appears missing. A single order badge cannot explain those differences because the physical units have separated.

The correct model is package-first: give every domestic tracking number its own row, attach an expected contents list, then connect the warehouse item IDs created from that package. This guide focuses on seller-to-warehouse splits, not the later decision to divide an international parcel.

Confirm that a real split exists

Open the detailed order and seller information. Count every distinct domestic tracking number and check whether the seller identifies which items or quantities belong to each. A changed number is not necessarily a second package; it may be a correction. Preserve the old and new values until the account or seller record explains the relationship.

A real split has two or more physical package records. Each should eventually have its own carrier events. Record when each number appeared and whether it has a physical acceptance scan. Do not label an unscanned number lost or delayed; first establish that the carrier took custody.

Create a package manifest before delivery

For every number, list product title, selected variant, quantity and seller. If the seller does not disclose the allocation, mark contents as unresolved instead of guessing. Record the total order quantity separately so the package manifests can later be reconciled against the whole order.

When several identical items are ordered, give them line labels such as item 1 and item 2, then connect warehouse IDs when they appear. Avoid using personal names or addresses. The purpose is to know which expected unit remains unaccounted for.

Track each package on its own clock

A package accepted on one date and another accepted later should not share one waiting period. Copy the first physical scan, latest event, delivered event and delivered location for each number. The order is partially complete when some packages arrive; that does not prove the seller failed to send the rest.

Use event evidence, not the most advanced sibling package, to evaluate each row. A delivered package moves into warehouse-intake reconciliation. A package still moving remains with the domestic carrier stage. An unaccepted number remains a seller-to-carrier question.

Match warehouse item records back to packages

When an item becomes visible in the warehouse, add its item ID and receipt time to the relevant package row. Verify title, option and quantity. If the package allocation was previously unknown, use the received evidence to update it while keeping a note that the mapping was learned at intake.

Do not mark the whole order stored because one item arrived. Calculate received quantity by order line and compare it with the original quantity. The unresolved unit should point to a specific package or an unknown allocation, not a generic missing-order label.

Recognize three partial-receipt patterns

One package still in transit

Warehouse records match the delivered package; another number has continuing carrier movement. Monitor the remaining physical handoff and keep the order open in the ledger.

All numbers show delivered, some items absent

Build an intake evidence pack for the delivered package associated with the missing contents. Package-level delivery and item-level receipt must be reconciled.

Seller shows more items than numbers can explain

Ask whether the seller combined contents, omitted a number or has not dispatched the remainder. Do not assign an item to a package without evidence.

Reconcile quantities without double counting

Use expected quantity, dispatched quantity, delivered package quantity where known, warehouse-recorded quantity and unresolved quantity. The totals should be calculated per variant. Two shirts in different sizes are not interchangeable for reconciliation even when the listing title is the same.

If the warehouse records one line with quantity two, confirm whether the interface represents two physical units or a grouped item record. Preserve the displayed evidence. Do not split or merge item IDs in your own ledger without labeling the editorial assumption.

Escalate the exact missing branch

  • For no carrier acceptance, provide the order ID and unaccepted seller number.
  • For carrier transit, retain the current carrier chronology.
  • For delivered but unmatched, provide delivery evidence and the expected package manifest.
  • For wrong quantity, provide the item ID, expected count and visible warehouse result.
  • For an unknown allocation, ask which tracking number contains the missing order line.

Do not send all packages as one “order stuck” case. The completed branches are useful proof that the order was split and that the warehouse can match at least some of the seller records.

Keep domestic splitting separate from international splitting

A seller split happens before warehouse storage and may be outside your choice. An international parcel split is a later planning decision among stored items. Using the same word for both can send an investigation to the wrong stage. Label the record “seller domestic package” or “international parcel” every time.

The existing consolidation-versus-split guide covers the later international decision. This article covers only matching seller packages to warehouse receipts.

Use a row-per-package worksheet

  1. Enter the parent order and exact line items.
  2. Add every domestic number and carrier.
  3. Record physical acceptance before treating it as dispatched.
  4. Attach the expected contents manifest.
  5. Add delivery evidence package by package.
  6. Connect warehouse item IDs and quantities.
  7. Calculate unresolved units.
  8. Record the resolving event without deleting earlier gaps.

The downloadable tracking worksheet can be adapted by duplicating rows for additional package numbers. Keep the file private because movement identifiers can reveal operational information.

Verify the order only after all branches close

A split order is reconciled when every expected unit is connected to a dispatched package and then to a warehouse item record, cancellation or other documented outcome. A green status on one package does not close the others. Mark each branch complete separately and then close the parent order.

This method makes partial progress visible without hiding missing goods. It also gives support the exact branch that needs action: the unaccepted number, in-transit package, unmatched delivery or quantity mismatch.

Use branch status instead of one parent badge

Assign each package a neutral state such as number created, carrier accepted, moving, delivered, intake matched or exception open. Calculate the parent order status from those branches rather than copying the most advanced event. If one of three packages is stored, the parent record should show one completed branch and two unresolved branches.

This approach also improves follow-up. You can filter only the branches awaiting a specific event, preserve completed evidence and avoid contacting the seller about goods that the warehouse has already recorded.

Preserve the split as part of the permanent identity chain

Once all items are stored, keep the domestic package mapping. Later warehouse questions may require the original seller number and delivery event. If items enter different international parcels, link those new parcel IDs as another branch rather than rewriting the domestic history.

A reliable record accepts that one order can become many packages and many items can later become another parcel. Tracking the branches is more work than copying one status badge, but it is the only method that consistently explains partial dispatch, partial delivery and partial storage.
