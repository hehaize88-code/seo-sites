Hoobuy Order Status & Forwarding FAQ

Use the answer that matches the responsible handoff. Live service screens and account information take priority over any general explanation.

Is HooBuys.net the official Hoobuy website?

No. HooBuys.net is an independent workflow and product-route guide. It does not process orders or control platform services.

What is the difference between a normal agent order and a forwarding order?

A normal agent order begins with a product link and an instruction for the agent to purchase. A forwarding order begins after you or another sender already purchased the goods and needs to route a domestic parcel to the warehouse.

Which identifiers should I save?

Save the source URL, selected variant, agent or marketplace order ID, domestic courier number, package count, forwarding order ID when applicable, warehouse item ID and parcel ID.

Does a created tracking number prove seller dispatch?

Not necessarily. Separate label creation from carrier acceptance, in-transit scans and delivery.

Why can delivery and warehouse receipt be different events?

A courier delivery scan records the carrier handoff. Warehouse intake, account matching, inspection and storage are later operational events.

Can one seller order have several domestic parcels?

Yes. Record the number of physical packages and each tracking number instead of assuming one checkout equals one box.

Can one forwarding parcel create several warehouse item IDs?

The public forwarding guide says numerous or large items may be photographed and stored separately, which can create multiple item records. Keep them linked to the original courier number.

What can QC photos verify?

They can help verify visible identity, quantity, colour, labels, measurements and obvious condition. They cannot prove authenticity, hidden construction, durability or fit.

When should I request another QC image?

Request a specific missing angle or measurement only when the current evidence cannot answer an important visible question. Check the live account for availability and price before requesting any service.

How long should a purchase or warehouse stage take?

The public sources reviewed do not establish one universal time for every seller, carrier, order and warehouse stage. Use any timing shown in the live account and escalate with the last verified event when it is exceeded.

What should a concise support packet contain?

Include one order or forwarding ID, the relevant courier number, package count, the last confirmed event, its date and one requested outcome. Exclude passwords, payment credentials and unrelated orders.

Does stored mean ready for international shipping?

Not automatically. QC approval, packaging, consolidation, route eligibility, actual or volumetric weight and final parcel payment are separate decisions.
