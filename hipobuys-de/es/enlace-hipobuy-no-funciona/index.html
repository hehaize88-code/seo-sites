El enlace de Hipobuy no funciona: solucionar la importación

Comprueba URL incompleta, producto incorrecto, variante, tienda no disponible y errores de importación antes de repetir un pedido Hipobuy.

Un enlace Hipobuy puede fallar en el anuncio original, la dirección copiada, la importación o la variante. Identifica el paso antes de modificarlo. Volver a pedir sin entender el error puede acabar en un artículo equivocado o un pago duplicado.

Esta guía trata fichas que no cargan, destinos incorrectos y tiendas no disponibles. No recupera inventario eliminado ni evita restricciones. Para buscar productos, utiliza la guía W2C y spreadsheets. Para paquetes enviados, consulta la guía de transporte.

Identificar el tipo de enlace

Una URL de marketplace, una ficha Hipobuy, una celda y un enlace corto no son intercambiables. Un spreadsheet puede apuntar a un artículo antiguo, una tienda o una redirección. La importación necesita identificar el anuncio concreto. Guarda siempre la dirección original.

Anota si aparece producto, inicio de sesión, portada, página inexistente o advertencia. Copia el mensaje exacto. «La fuente abre, pero la importación muestra tienda no disponible» sirve más que «no funciona». Comprueba si el problema solo aparece tras elegir talla o color.

Copiar la URL completa

Usa la función de compartir de la ficha real cuando exista. Un texto copiado puede mezclar título, puntuación, código y dirección. Separa la URL sin eliminar dominio, ruta ni parámetros que identifican el producto.

No deduzcas identificadores desde el nombre ni borres todos los parámetros porque el enlace sea largo. Algunos determinan el artículo o la plataforma. Si un enlace corto funciona, copia la dirección final. No introduzcas credenciales en una redirección desconocida para recuperar una URL.

Abrir el anuncio original por separado

Comprueba el producto en la web o aplicación normal del marketplace. Una exigencia de acceso o una limitación regional no equivale a un anuncio eliminado. Si tampoco abre allí, busca una ficha actual o pregunta al vendedor. Una fila antigua no es una oferta vigente.

Si la fuente funciona, compara vendedor, imagen, identificador y variantes con la importación. Guarda una captura fechada cuando difieran. Ver una imagen no confirma disponibilidad en la talla y color concretos que deseas.

Separar errores y restricciones

Las fichas públicas Hipobuy pueden indicar que una tienda no está accesible o que sus productos o servicios no cumplen los estándares de la plataforma. Eso no es un simple carácter incorrecto. Lee el aviso antes de reconstruir el enlace.

No utilices pedidos manuales para eludir restricciones. Consulta al soporte oficial si la fuente y el artículo se aceptan y cuál es el siguiente paso autorizado. Puede que no se pueda gestionar la compra. Cambiar el formato de la URL no cambia la elegibilidad del producto.

Revisar navegador y sesión

Si la fuente es válida y no hay restricción, actualiza una vez y revisa la conexión. Prueba la misma URL legítima en otro navegador actualizado o la aplicación habitual. Así distingues un fallo local de un problema de importación sin repetir compras.

Extensiones, scripts bloqueados y sesiones caducadas pueden afectar la pantalla. Cambia un solo factor cada vez. No desactives protecciones ni instales un «reparador de enlaces» desconocido. Verifica el dominio antes de volver a iniciar sesión y no entregues tu contraseña a terceros.

Verificar la variante después del éxito

Que la página cargue no completa la revisión. Confirma vendedor, artículo, color, talla y cantidad. Compara precio de la variante y separa depósito o envío interior. Una imagen idéntica puede acompañar opciones con precios diferentes.

Lee la tabla de medidas de ese anuncio, sin copiar tallas de otro vendedor o una marca familiar. Confirma accesorios, embalaje y contenido incluido. Guarda la selección antes de pagar para comparar después las fotos QC con el pedido correcto.

Solicitar ayuda manual cuando corresponda

Si existe Custom Order u otra compra manual para esa fuente, lee las instrucciones actuales y confirma que se acepta el artículo. Aporta enlace exacto, variante, cantidad y requisitos. Pregunta cómo se confirmarán precio, transporte interior y servicios.

Forwarding Order describe otro proceso: productos comprados por separado y enviados a un almacén. No sustituye automáticamente una importación fallida. Aclara quién compra, paga al vendedor, identifica los productos en almacén y tramita devoluciones. Resuelve responsabilidades antes de seguir.

Preparar una consulta útil

Envía enlace completo, plataforma original, captura del error, momento y pruebas realizadas. Incluye variante si influye. Si hay un pedido, añade referencia y estado del pago para separar acceso y transacción existente.

Oculta direcciones, saldos, datos de pago y sesión antes de publicar capturas. El soporte privado puede necesitar una referencia; una comunidad no necesita credenciales. Formula una pregunta concreta sobre la fuente o la variante importada.

Comprobar pedidos antes de intentarlo de nuevo

Un error después de confirmar no demuestra que no exista pedido. Revisa compras y pagos por artículo, cantidad y hora. Si el proveedor registra una transacción y la cuenta no, guarda ambos estados y solicita conciliación antes de pagar otra vez.

Cuando se resuelva, actualiza tu enlace guardado y fecha de revisión. Anota la variante aparte, porque una URL no siempre conserva la selección. Precio y stock deben comprobarse en cada compra.

Diagnóstico rápido

  • Fuente eliminada: buscar anuncio actual o preguntar al vendedor.
  • URL incompleta: copiar la dirección de la ficha real.
  • Tienda restringida: leer el aviso y contactar al soporte oficial.
  • Artículo incorrecto: comparar identificador y variantes.
  • Pago incierto: conciliar registros antes de repetir.
  • Importación correcta: continuar con presupuesto total y QC.

Conserva las pruebas hasta aclarar producto y pago. El objetivo es un pedido identificado, admitido y con coste comprensible, no solo una página que abra.
