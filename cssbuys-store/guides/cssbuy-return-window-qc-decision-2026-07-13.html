Warehouse timing · QC evidence · return decisions

Free warehouse storage and a seller return window solve different problems. Storage time answers how long an item may wait before international shipment. The return window answers how quickly a buyer must identify a problem and act while a seller may still accept the item back. Confusing the two can turn a visible QC issue into an item that is difficult or impossible to return.

The public rule reviewed for this guide distinguishes ordinary goods, which may receive up to 90 days of free storage, from sensitive goods, which may receive 30 days. Public return guidance also describes a much shorter condition: the seller must accept the return, the item should have been in the warehouse for less than seven days, and the buyer pays the domestic return shipping. These rules can change, so the current order account remains the final reference.

There are two clocks, not one

The longer storage clock is mainly a consolidation tool. It gives a buyer time to wait for other purchases, decide how to group items and prepare an international parcel. It does not guarantee that the original seller will accept a return throughout that period. An item can remain physically stored while the practical opportunity to return it has already narrowed.

The shorter clock starts when the item reaches the warehouse and evidence becomes available. That is when the order option, warehouse photos and visible condition should be reviewed. Waiting for every other item to arrive before opening the first QC set is convenient, but it concentrates several decisions near the deadline. A safer habit is to review each item on its own arrival day.

Build an arrival-day record

Start with the order identity. Save the selected colour, size or model, the seller image used to make the purchase, and any measurement table that affected the choice. Then compare those details with the warehouse record. This prevents a common mistake: inspecting the quality of the wrong option without first noticing that the wrong option arrived.

Record the in-warehouse date beside the product route. The exact date matters more than a vague note such as “arrived this week.” If the item needs a measurement or close-up, the request can be made immediately. If the evidence shows a wrong size, missing part or serious visible defect, the buyer can begin the return inquiry while the timeline is still clear.

Triage before inspecting small details

A fast first pass should look for issues that independently justify action. Is the ordered option correct? Is the item complete? Is there an obvious stain, crack, tear or severe shape problem? Do the visible labels and measurements contradict the order? These checks deserve priority because they are easier to explain and document than subjective concerns about minor finishing.

The second pass can examine category-specific construction. Shoes need both size labels, pair symmetry, outsole joins and visible condition. Clothing needs chest or waist measurements, garment length, colour and major seams. Jackets need zipper alignment, cuffs, panels and fill distribution where visible. Accessories need hardware alignment, clasp condition and missing components.

Ask for evidence that changes the outcome

If the standard photos do not answer the question, define the decision before requesting more evidence. “Return if the chest is below 58 cm” is actionable. “Take better pictures” is not. A specific request should name the part, the angle and the measurement reference so the resulting image can support a decision rather than add another decorative view.

Do not assume every special request is free or available. The account interface and current support response should confirm what can be provided and whether a charge applies. The same caution applies to video, unusually detailed measurements and other services whose public pricing may not be stable.

Separate defects from expected variation

Not every difference is a defect. Lighting can change colour appearance. Soft garments can look uneven when folded. Printed or washed items may show natural variation. A return request is stronger when it identifies a concrete mismatch: the wrong option, a measurement outside the stated basis, a missing component, visible damage or a construction problem that affects use.

Keep wide and close views together. A close-up proves the detail; a wider view proves where that detail sits on the item. For a seam problem, one image should show the affected section and another should show the surrounding panel. For a measurement, the tape should lie flat and both endpoints should be readable.

Use a simple decision matrix

KeepThe option matches, essential measurements are acceptable and no decision-changing visible issue remains.
Request evidenceOne specific question remains and a targeted photo or measurement can answer it.
Ask about returnThe item is wrong, incomplete, visibly damaged or outside an important stated measurement.
Do not delayThe issue may justify return and the warehouse arrival date is approaching the stated time condition.

This matrix prevents perfectionism from consuming the whole window. It also prevents a buyer from approving an item merely because the photos look attractive. The decision is tied to the ordered option, functional measurements and visible condition.

Shipping comes after the keep decision

International shipping research is important, but it should not distract from a return decision. First decide whether the item belongs in the parcel. After that, consider actual weight, dimensions, product attributes, available lines and packaging. A shoebox may increase volume. A thick jacket may be compressible, while a structured accessory may need protection.

The final parcel amount can differ from an early estimate because packed dimensions and verified weight are not known at the product-discovery stage. A product page should therefore avoid promising a fixed shipping price. The useful preparation is to note shipping sensitivity and recheck the live calculator after the retained items and packaging plan are known.

Keep the evidence together

A compact record can contain the product title, exact route, selected option, warehouse date, QC question, evidence received and final decision. If a return inquiry is needed, this record reduces confusion. If the item is kept, the same record becomes a useful reference for future sizing and category choices.

This approach also improves product-find content. Instead of saving a link without context, the page can explain what was checked and which uncertainty mattered. The result is more helpful than repeating the same shipping and coupon FAQ under every article.
